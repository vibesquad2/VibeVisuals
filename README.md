# VibeVisuals

Клиентский визуальный мод для **Minecraft 1.21.11 / Fabric** (loader 0.19.5).
Ничего не требует от сервера: чистая клиентская графика, оверлеи и эффекты.
Текст интерфейса мода (ClickGUI, HUD, редактор, Alt Manager) рисуется гладким шрифтом **Golos Text**
(TrueType, SIL OFL 1.1), встроенным в мод, — вместо пиксельного шрифта Minecraft. Весь интерфейс
оформлен в тёмном **неон/киберпанк** стиле: срезанные углы панелей, неоновые контуры и свечение,
сканлайны, общая палитра cyan / magenta / lime / amber. Заголовок игрового окна —
**VibeVisuals - t.me/vibevisualss**.

## Управление

| Действие | Клавиша по умолчанию |
| --- | --- |
| Открыть / закрыть ClickGUI | `Right Shift` |
| Зум (удерживать) | `C` |

Обе клавиши можно переназначить в обычных настройках управления Minecraft (категория
«VibeVisuals»). ClickGUI — одно окно: слева список категорий, справа функции выбранной категории.
`ЛКМ` по функции — включить/выключить её, `ПКМ` по функции — только раскрыть или свернуть её
настройки (значения при этом не меняются), `СКМ` (средняя кнопка мыши) по любой функции или её
тумблеру — забиндить на него клавишу (дальше нажать нужную клавишу, `Backspace` — очистить бинд,
`Esc` — отмена; в игре бинд переключает выбранное с сообщением над хотбаром), перетаскивание —
слайдер, у режимов (например, типа питомца или стиля Target ESP) — отдельные кнопки-карточки
вместо галочек, колесо мыши — прокрутка списка, `ESC` или `Right Shift` — закрыть.
Кнопка **Edit HUD** внизу открывает редактор HUD, он же открывается командой `/vibevs hud` прямо
из чата: перетаскивание — двигать элемент, `ПКМ` — сброс позиции, **RESET LAYOUT** — применить
новую неоновую раскладку, `Esc`/Done — назад. Все настройки сохраняются в `config/vibevs.json`
(с задержкой 2 секунды после последнего изменения).

## Команды

| Команда | Что делает |
| --- | --- |
| `/vibevs hud` | открыть редактор расположения HUD (то же, что кнопка Edit HUD) |
| `/vibevs gui` | открыть ClickGUI |
| `/vibevs` | справка по командам |

## Главное меню

Ванильный экран заголовка заменён собственным synthwave-экраном: неоновое солнце, силуэт города,
перспективная сетка и сканлайны; логотип `VibeVisuals` с глитч-эффектом, кнопки
**Singleplayer / Multiplayer / Alt Manager / Options / Quit Game** в неоновых рамках, чип
**ClickGUI** в правом верхнем углу и подписи версии/соцсети снизу. Экран отключается настройкой
**Custom Main Menu** в категории Overlay & HUD.

В списке мультиплеера сверху закреплён сервер **piglax.ru** с названием
**ЛУЧШИЙ СЕРВЕР МАЙНКРАФТ**. Запись добавляется автоматически при загрузке списка серверов,
поэтому она есть даже в свежей папке игры.

## Alt Manager

Кнопка **Alt Manager** в главном меню открывает менеджер локальных ников для **пиратки /
offline-mode**. Лицензия и Microsoft-вход не поддерживаются: в списке хранятся только имена,
токены и пароли не сохраняются. Смена ника применяется сразу в текущей сессии и сохраняется
в `config/vibevs-alts.json`; при следующем запуске выбранный ник применяется автоматически.
Имя текущего лаунчер-аккаунта добавляется в список при первом запуске, чтобы можно было
вернуться к нему.

- поле ввода и **ADD** — добавить ник (3–16 символов: `A-Z`, `a-z`, `0-9`, `_`) и сразу
  переключиться на него; нажатие `Enter` делает то же самое;
- **RANDOM** — сгенерировать уникальный ник длиной **от 4 до 12 символов** в поле ввода;
- клик по строке — переключиться, `×` — удалить ник (активный ник удалить нельзя), колесо
  мыши — прокрутка списка, `ESC` — закрыть.

Для каждого ника создаётся offline-UUID Mojang (`OfflinePlayer:<ник>`), поэтому на
offline-серверах сохраняется привычная привязка аккаунта. Переключение на лицензионный
online-mode сервер не поддерживается — это offline-менеджер.

## Категории

- **Sky & Weather** — сдвиг оттенка неба, постоянный закатный градиент, множитель плотности
  тумана, отключение дождя/снега, режим **Snow** (весь дождь рисуется снегом; приоритетнее
  No Weather), яркость звёзд.
- **Overlay & HUD** — удаление виньетки, красной подсветки урона, блура тыквы и оверлея
  спайгласса. Вся настройка HUD собрана в одну функцию **HUD** (ЛКМ — мастер-вкл/выкл, ПКМ —
  настройки): кастомный прицел с размером, строки инфо-оверлея (FPS, координаты, скорость, биом,
  направление, пинг), тонировка экрана (hue + сила) и самостоятельные элементы нового неонового
  HUD:
  - **Brand Card** — карточка слева сверху с градиентным знаком V, надписью `VIBEVISUALS`,
    строчным хэндлом `t.me/vibevisualss` и пульсирующим live-индикатором;
  - **Status** — двухколоночная стеклянная панель с пиксель-иконками: FPS и пинг подсвечиваются
    по качеству, скорость, координаты, биом и направление собраны в аккуратную сетку;
  - **Keybinds** — карточка справа сверху, только включённые функции с забинженной клавишей
    (`GUI` и `Zoom` не показываются), строки отсортированы по имени, клавиша — в отдельном кейкапе;
  - **Effects** — карточка справа снизу: рамка с ванильной иконкой эффекта, название, живой
    таймер и тонкая полоска остатка времени;
  - **Target HUD** — компактная карточка под прицелом: голова в неоновой рамке, имя, тип цели,
    число HP и плавная полоска здоровья с красным шлейфом после урона; голова краснеет при
    попадании. Появляется только когда цель в зоне удара;
  - **Custom Crosshair** — тонкие лучи, ромб в центре и внешние точки; при наведении на живую
    цель прицел становится розовым и «дышит».

  Каждый элемент отключается отдельно. В редакторе HUD элементы двигаются ЛКМ, ПКМ сбрасывает
  позицию, а кнопка **RESET LAYOUT** применяет новую раскладку по умолчанию: бренд и статус слева,
  кейбинды справа сверху, эффекты справа снизу, Target HUD по центру под прицелом. Здесь же —
  **Custom Main Menu**: кастомный экран заголовка вместо ванильного.
- **Color & Post** — night vision, радужные акценты GUI/HUD, дополнительная тряска камеры при
  уроне.
- **Effects & Particles** — трейл за игроком, **хит-партиклы** с двумя стилями, выбираемыми
  отдельными неоновыми кнопками в раскрытой строке Hit Particles: **Burst** (ударная волна,
  разлёт искр-линий и короткая орбита вокруг цели) и **Web** (мини-паутинки с крошечными
  ползающими пауками), амбиент-частицы (пыль днём, светлячки ночью), трейл
  стрел/тритонов/метательных предметов, **Pets** — косметический питомец, который следует за
  игроком: кошка, собака, мопс, призрак или мини-фигурка в вашем скине. В модуле есть размер и
  скорость питомца (по умолчанию 70%, чтобы все питомцы двигались спокойнее), а также
  **Target ESP** — кастомный контур вокруг игрока/моба из прицела (не ванильный glow). Все
  партиклы и питомцы рисуются собственной геометрией мода через
  `WorldRenderEvents.AFTER_ENTITIES`, без `ParticleTypes`, ванильного particle engine, сущностей
  и каких-либо пакетов. В Target ESP теперь один выбранный режим, а не набор галочек: **Box**,
  **Orbs**, **Ring**, **Ghost**, **Skull** и **Chains** выбираются отдельными кнопками в
  раскрытой строке Target ESP. Все шесть режимов рисуются собственной геометрией мода — никаких
  ванильных партиклов и glow. Вместе с Target HUD показывается только когда цель в зоне удара
  (ванильная дальность атаки).
- **Tools** — fullbright, зум (вкл/выкл, сила, плавность), отключение наклона камеры при уроне,
  **PvPSafe** — подтверждение перед выходом из мира/сервера и закрытием игры (анти-релог; при
  попытке Alt+F4 запрос закрытия окна тоже перехватывается).

## Как это устроено

| Миксин / хук | Зачем |
| --- | --- |
| `GameRendererMixin` | множитель FOV для зума, отмена/добавление наклона камеры при уроне |
| `LightTextureMixin` | fullbright (brightness сверх ползунка) и night vision через lightmap-шейдер |
| `GuiMixin` | отключение виньетки, спайгласса, блура тыквы и ванильного прицела |
| `EnvironmentAttributeProbeMixin` | цвет неба/тумана, дистанция тумана, яркость звёзд |
| `WeatherEffectRendererMixin` | пропуск отрисовки дождя/снега и всплесков, режим «всё — снег» |
| `LivingEntityRendererMixin` | убивает красную подсветку урона на моделях |
| `MinecraftMixin` | кастомное главное меню вместо TitleScreen, подтверждение выхода (PvPSafe) и заголовок окна `VibeVisuals - t.me/vibevisualss` |
| `MinecraftAccessor` | замена финальных полей сессии Minecraft при переключении offline-аккаунта |
| `MultiPlayerGameModeMixin` | запуск кастомной хит-вспышки в точке удара |
| `ServerListMixin` | закрепление сервера `ЛУЧШИЙ СЕРВЕР МАЙНКРАФТ` (`piglax.ru`) первым в списке мультиплеера |
| `EntityRendererMixin` | кастомная отрисовка выбранного режима Target ESP (`submitCustomGeometry` + `RenderTypes.lines()`) |
| `Particles` (renderer) | собственные партиклы: линии, кольца, искры, орбиты, паутины и мини-пауки через `WorldRenderEvents.AFTER_ENTITIES`; ванильный particle engine не используется |
| `AltManager` / `AltManagerScreen` | offline-ники, генерация 4–12 символов, переключение сессии и `config/vibevs-alts.json` |

## Сборка

Нужен **JDK 25** — его требует Gradle-плагин Loom 1.19.1. Сам мод компилируется под Java 21
(`options.release = 21`), как и положено для 1.21.11.

```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-25.0.4.101-hotspot"
.\gradlew.bat build          # jar в build/libs/
.\gradlew.bat runClient      # запуск тестового клиента в 1920x1080
```

Тестовый клиент по умолчанию стартует в **1920×1080** (аргументы `--width`/`--height` в
`build.gradle` и `overrideWidth`/`overrideHeight` в `run/options.txt`); игровые скриншоты `F2`
сохраняются в 1920×1080. Полноэкранный режим — `F11`.

## Структура

```
src/main/java/dev/vibevs/           — общий код, конфиг, утилиты
src/main/resources/                 — fabric.mod.json, ассеты, mixin-конфиг
src/client/java/dev/vibevs/client/  — фичи, ClickGUI, HUD, миксины рендера
src/client/resources/               — клиентский mixin-конфиг, шрифт Golos Text и его лицензия
```

Логика: каждая настройка — публичное поле `VibeConfig` + запись в реестре `Visuals`; там же в
`buildFeatures()` функции собираются в пары «мастер-тумблер + дочерние настройки». ClickGUI и HUD
работают с реестром, поэтому новая фича = поле + строка регистрации + строка группировки.
